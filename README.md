# SNOP (Self-care, Negative Symptoms and Olfaction in Psychosis)

SNOP (Self-care, Negative Symptoms and Olfaction in Psychosis) Study: Contribution of olfactory assessment to multidomain phenotyping in people with psychosis. An exploratory study with a 6-month follow-up.

Estudio SNOP: Contribución de la evaluación olfativa al fenotipado multidominio en personas con psicosis, síntomas negativos y déficits de autocuidado. Estudio exploratorio con seguimiento a 6 meses.


# Author

Software developed by **Santiago Latorre Martínez** for the **SNOP study** (Exploratory study of olfactory impairments in psychosis).

Research conducted at **Parc Sanitari Sant Joan de Déu** in collaboration with the **Fundació de Recerca Sant Joan de Déu**, subject to the corresponding institutional policies on intellectual property.

The software is released as open source to facilitate transparency, reproducibility and scientific collaboration.

## Included tasks

### Baron-Cohen Face Test (BCFT)

This repository includes an original digital implementation of the Baron-Cohen Face Test for research purposes. The software implementation is original; however, the assessment instrument itself, including its conceptual design and any protected materials, belongs to its original authors.

Spanish validation and documentation:

Caballero Martínez L, et al. **Baron-Cohen Face Test (Spanish version).** CIBERSAM Instrument Repository. https://bi.cibersam.es/busqueda-de-instrumentos/ficha?Id=488

Please cite both the original publication of the instrument and the Spanish validation when appropriate.

### Probabilistic Reversal Learning Task (PRLT)

This implementation was developed independently for the SNOP study and is inspired by previously published probabilistic reversal learning paradigms, particularly those described by Den Ouden and colleagues. The implementation, task structure, software architecture, parameterisation and stimulus presentation were developed specifically for this project.

Please cite the relevant methodological publications describing the original PRLT paradigm when using this implementation.

### Fish Task

This repository includes an original implementation of the Fish Task inspired by the classical Beads Task literature. The implementation, graphical interface, stimulus presentation, task flow and configurable parameters were developed specifically for this project.

Please cite the original Beads Task / Fish Task methodological publication when using this implementation.
